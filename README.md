# EliteTee

EliteTee is a premium golf social platform built for serious golfers to share rounds, discover great courses, and build trusted relationships through the game.


🌐 Live Website: https://elitetee.club

EliteTee was created after spending more than 14 years working inside some of America’s most respected private golf clubs.

The goal is to modernize how private club members connect while preserving the exclusivity, trust, and etiquette that make private clubs unique.

Features

✅ Membership application

✅ Responsive design

✅ Modern landing page

✅ Formspree application system

✅ Supabase backend

✅ GitHub + Vercel deployment

Tech Stack

* React
* TypeScript
* Vite
* Supabase
* Vercel
* Formspree
* GitHub
* Cursor AI

  Why I Built It

I spent over a decade working at private clubs including:

* National Golf Links
* Shinnecock Hills
* McArthur Golf Club
* Sebonack
* La Gorce
* Calusa Pines

EliteTee combines that firsthand industry experience with modern web development to create a trusted network for private club members.

Future Roadmap

* Member authentication

* Club verification
* Member profiles
* Travel introductions
* Mobile application
